# Material Symbols Outlined

Official Google Material Symbols, Apache License 2.0 (see `material-symbols-LICENSE.txt`).

Self-hosted WOFF2 subset, updated 2026-10-25. Static axes: `wght=300`, `opsz=24`, `FILL=0`, `GRAD=0`.

Included glyphs: `arrow_forward`, `arrow_outward`, `chevron_left`, `chevron_right`, `close`, `undo`.

Source: https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@24,300,0,0&icon_names=arrow_forward,arrow_outward,chevron_left,chevron_right,close,undo&display=block

Guide: https://developers.google.com/fonts/docs/material_symbols

When adding an icon, extend the subset and the name union in `components/MaterialIcon.tsx` together. The application makes no runtime requests to Google Fonts.
